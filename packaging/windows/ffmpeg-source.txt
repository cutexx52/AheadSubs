FFmpeg corresponding source and build instructions

AheadSubs uses FFmpeg under the GNU Lesser General Public License, version 3
or later. See COPYING.LGPLv3, COPYING.GPLv3 and CREDITS. The source ZIP named
in SOURCE.txt is available alongside the Windows binary release. It contains
the exact unmodified FFmpeg source archive and our Windows build script. It
also contains the MSYS2 source package and terms for the shipped winpthreads
DLL, used by the UCRT64 build for POSIX clock and sleep functions.

To rebuild, extract that ZIP. In an MSYS2 UCRT64 shell, install diffutils, make,
mingw-w64-ucrt-x86_64-gcc and mingw-w64-ucrt-x86_64-nasm. The binary package's
toolchain.txt records the package versions used. From an empty directory run
`bash /path/to/build-ffmpeg.sh /path/to/ffmpeg-<revision>.tar.gz /path/to/output 4`.

Exit AheadSubs and its background service, then replace the matching .exe and
.dll files together in the program's bin directory with those produced under
output/aheadsubs-ffmpeg/bin. Back up the existing files to allow rollback. For
an independently writable test copy, extract the portable AheadSubs ZIP.

FFmpeg 对应源码和构建说明

AheadSubs 使用按 GNU 宽通用公共许可证第 3 版或更新版本授权的 FFmpeg。
许可证及署名见 COPYING.LGPLv3、COPYING.GPLv3 和 CREDITS。SOURCE.txt 所列的
源码 ZIP 随 Windows 二进制一起发布，内含确切的原始 FFmpeg 源码及构建脚本，
以及 UCRT64 用于 POSIX 时钟和休眠的 winpthreads DLL 的 MSYS2 源码包及许可。

重新构建时先解压源码 ZIP。在 MSYS2 UCRT64 中安装 diffutils、make、
mingw-w64-ucrt-x86_64-gcc 和 mingw-w64-ucrt-x86_64-nasm。二进制包内的
toolchain.txt 记录了构建所用版本。在空目录运行
`bash /path/to/build-ffmpeg.sh /path/to/ffmpeg-<revision>.tar.gz /path/to/output 4`。

退出 AheadSubs 及其后台服务，再用 output/aheadsubs-ffmpeg/bin 下相匹配的
.exe 和 .dll 一起替换程序 bin 目录中的文件。先备份原文件，以便回退。
如果希望在独立、可写的副本上测试，可以解压 AheadSubs 便携 ZIP。
