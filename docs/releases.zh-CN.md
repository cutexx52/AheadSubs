# 发布与 Actions 预算

[English](releases.md) | [简体中文](releases.zh-CN.md)

## 实施计划

- 每日检查；距上次成功发布满 72 小时且有影响发行程序的改动才发布预览版。
- 仅用标准 GitHub Linux/Windows runner；仓库变为私有时停止自动发布，避免默默消耗付费计算资源。
- 固定提交构建并验证标准版与 CUDA x64 的安装包、便携包；全部成功才发布。稳定版继续通过显式版本标签发布。
- 避免长期保留 Actions 构建产物及模型缓存，二进制文件存放为 Release 附件，验证校验和、大小上限，说明重试和失败行为。
- 所有维护的 Markdown 页面以英文为默认，提供互相对应的简体中文链接，并在 CI 检查覆盖及链接。

验收：离线调度测试、文档检查、完整服务测试、两种 Windows 包验证、独立 PR 审查，然后合并。
