# Windows 桌面助手

[English](desktop.md) | [简体中文](desktop.zh-CN.md)

## 日常使用

在 **字幕** 首页展开 **快速预设**，检查所需的模型、运行库和密钥。缺少模型时可以 **立即下载**，也可以去 **管理模型** 查看标出的缺项。下载完成后点击 **应用方案**，字幕的源语言、目标语言和双语选项保留。预设默认折叠；手动搭配的设置显示为 **自定义**。

| 预设 | 语音识别 | 字幕翻译 |
| --- | --- | --- |
| 纯本地 · CPU | Whisper Small · CPU | NLLB · CPU |
| 纯本地 · 独显入门 | Qwen3-ASR 0.6B · Vulkan | NLLB · CPU |
| 纯本地 · 高性能 GPU | Qwen3-ASR 1.7B · Vulkan | NLLB · NVIDIA CUDA |
| 作者推荐 · 本地识别 + 云端翻译 | Qwen3-ASR 1.7B · Vulkan | Qwen-MT Flash · 百炼 API |

独显方案检查 Vulkan 设备，高性能方案另外检查 CUDA 设备和运行库。推荐方案检查已保存的百炼密钥是否可读取以及地址格式；实际凭据是否有效由服务请求验证。配置并保存密钥后返回首页会重新检查。下载失败后可再次点击 **立即下载**，已完整下载的模型会被复用。

**本地模型**分为语音识别、字幕翻译和语音检测。Whisper 和 NLLB 可独立选 CPU 或 NVIDIA CUDA，点 **保存并应用** 生效。旧配置沿用已有设备选项。运行中的模型要先切换或停止服务，再卸载。Whisper 和 NLLB 的下载放在 Hugging Face 共享缓存中，卸载会移除对应仓库的缓存。Qwen3-ASR 卸载会保留共享的约 0.63 GB 的对齐模型和运行库，其他版本可继续使用。Silero 随环境提供，FSMN 在 **高级设置** 中选用后准备。

**云端模型**可按供应商选择 **密钥文件** 或 **直接填写**。直填内容用 Windows 当前用户的 [DPAPI](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata) 加密保存。文件模式保存所选文件的路径。删除直填密钥时，切回 **默认（环境变量）** 并保存。百炼的识别和翻译共用密钥及区域地址，自定义识别和翻译可以各用一把。远程自定义接口发送密钥时使用 HTTPS，本机回环地址支持 HTTP。可以先 **保存密钥**，再到「字幕」页应用设置。

选择 **ChatGPT 订阅 · OAuth** 可以在浏览器授权 AheadSubs 使用 ChatGPT 订阅做字幕文本翻译。MiniMax 支持 M Plan 专用 Key 和按量 API Key。参见[推理与翻译后端](providers.zh-CN.md)。

**上下文增强**按翻译模型保存。支持前文的模型可参考 0–8 个已识别的前文片段，每段默认最多 250 字符，可设为 20–1000 字符。请求优先保留最近的前文，总计最多 1000 字符，输出仍对应当前字幕。前文有助于改善指代和术语的翻译，也可能增加 token 用量和延迟。设为 0 时仍可使用翻译提示词。Qwen-MT Flash 和 Plus 只提供风格提示词。

设置窗口为单实例。关闭窗口后可双击 Windows 托盘图标重新打开。托盘菜单的 **停止字幕服务** 释放模型资源并保留窗口入口，**停止并退出** 同时关闭助手。退出后重新运行助手并启动服务，播放器才能继续提交新任务。已经写入磁盘的缓存可复用。

## 自动字幕任务

在 **自动任务** 中监控多个目录。每条规则有自己的文件过滤条件和字幕配置。默认写入媒体同目录。字幕以媒体文件主名、可选后缀和 `.srt` 命名，并保留已有字幕文件。

1. 打开 **自动任务 → 添加规则**，选择要监控的目录。勾选 **包含子目录** 可扫描目录树。默认只处理新增或修改的文件，勾选 **处理现有文件** 可把目录里的现有文件也加入队列。
2. 在 **文件过滤** 中可填写不区分大小写的文件名正则，例如 `^第.*集\.mkv$`。文件还必须满足扩展名和大小范围，大小上下限均包含边界，单位为 MiB。最大大小留空表示不设上限。如果正则匹配超时，目录会暂停扫描，后续扫描成功后恢复。
3. 在 **字幕配置** 中分别选择语音识别和字幕翻译模型，并设置语言、音轨（从 1 开始编号）和 SRT 内容。新建和已有规则默认 **沿用全局设置**，使用当前服务为对应阶段选定的模型。另选输出目录时会保留源目录下的相对层级。例如后缀设为 `.en` 会生成 `第 01 集.en.srt`。如果多个媒体文件对应同一个输出路径，会保留先生成的 SRT。
4. 点击 **保存规则**。如服务未运行，再点击主窗口的 **保存并启动**。空闲阈值默认为 0，此时等待 AheadSubs 播放会话、文本翻译和手动重新生成结束。设为正数时，还需在设定分钟数内没有 Windows 键盘或鼠标输入。

桌面管理的字幕服务运行时，即使窗口隐藏到托盘也会继续处理。任务之间约每 10 秒扫描一次，连续两次扫描确认文件大小与时间戳未变后才生成字幕。每次处理一个文件，同一时间只提交一个分块。开始播放后，正在运行的分块可以完成，后台暂停提交新分块，重新空闲后从缓存续跑。暂停规则或停止服务会保留队列。修改现有规则的输出选项会将该规则之前接收的文件重新排队，已有 SRT 始终保留。

所选本地模型需先在 **本地模型** 中安装。云端模型使用应用保存的凭据和供应商设置，包括已配置的 ChatGPT 账号和模型，或自定义 API 地址。在 **字幕** 页应用供应商设置的更改。例如，日剧规则可以选择 Whisper Small 和 Qwen-MT Flash，而课程目录可以沿用两个全局模型。不同模型组合生成的字幕会保存为独立的缓存版本。若要保留旧 SRT 并生成新文件，请改用不同的后缀或输出目录。

选中规则可查看等待、进行中、已完成、已跳过和失败的数量。补齐模型或修复供应商设置、媒体错误后，可点击 **重试失败文件**。队列和规则保存在应用数据目录的 `folder-tasks.sqlite3` 和 `folder-tasks.json` 中。扫描会跳过符号链接和目录联接点。请按希望交给云服务处理的媒体范围启用云端识别或翻译。

## 字幕库

打开 **字幕库**，按文件名或路径搜索，也可按主要源语言筛选。文件按记录的路径归并，默认打开最新版本，可切换到历史版本。移动文件会产生新的条目。升级前只记录文件名的条目保持独立，直到以相同缓存条件重放并补记路径。

覆盖率表示选定版本已处理的时间占媒体总时长的比例，静音也计入；缺少时长时显示未知。主要源语言按识别片段的时长统计，未提供语言的后端会显示未知。筛选按该文件最近一个有语言记录的版本进行。已有字幕的目标语言从该文件的各版本汇总。

选择 **重新生成** 后，运行中的服务会按所选版本的音轨及语言、当前服务的模型生成新版本，一次处理一个文件。后台只在播放会话空闲时启动下一段。任务失败或服务退出时会保留已写入的字幕和旧版本，可以刷新查看状态并再次生成。文件移动或替换后，先重新播放以记录新文件。

**打开 SRT** 在记事本中查看所选版本的目标字幕。**另存 SRT** 可保存同一内容，包括所选版本已经生成的全部字幕，适用于尚未处理完整的文件。历史路径、生成状态和字幕保存在本机缓存中。

## 状态页

打开侧栏的 **状态**。页面打开时立即刷新，页面和窗口可见时每 3 秒刷新。也可点击 **立即刷新**。

| 区域 | 查看内容 |
| --- | --- |
| 字幕服务 | 服务是否就绪，以及 PotPlayer、mpv、命令行、MCP 和其他 HTTP 客户端的活跃播放连接和正在处理的文本请求数。 |
| 模型与本机资源 | 启用的识别、翻译和语音活动检测模型及其运行设备和加载状态。CPU、RAM、GPU 及独立显存统计覆盖后台及其采样时存活的子进程。不支持的指标留空。 |
| 字幕性能 | RTF 中位数、字幕就绪延迟 P50/P95/P99 和样本数。RTF 低于 1 表示处理用时短于对应音频的播放时间。性能样本在内存中保留最多 15 分钟，重启后重新采样。 |
| 云端用量 | 按提供商、模型、用途显示本机调用、失败、已知用量及美元估算。可选本周或之前 7 个 UTC 自然周。订阅、缺少用量或费率的调用会显示对应状态。 |

在支持的播放器中开启预读后，页面会显示实时指标。服务停止或未响应时，仍可从桌面缓存里的 `cloud-usage.sqlite3` 查看已有周汇总。服务启动或写入用量时清理过期周。状态指标不记录媒体路径、字幕、账号、密钥、会话 ID 或请求内容。测量和估价口径见[状态指标](server.zh-CN.md#状态指标)。

## 诊断模式

正常模式关闭诊断日志。遇到问题时，在 **高级设置** 勾选 **启用诊断日志** 并应用，再复现问题。若需要诊断整段播放器会话，可以停一次预读再开启。用 **打开日志目录** 查看结果。命令行可用 `python -m aheadsubs serve --diagnostics`。

源代码助手把服务和播放器日志保存在 [Windows 用户数据目录](windows.zh-CN.md)。分享诊断前，检查记录中的本地文件路径、主机名和 URL。定位结束后可以关闭诊断模式。

## 模块接口

打包启动器运行 `UI/AheadSubs.exe`。WPF 界面使用 `python -m aheadsubs.desktop.bridge` 管理后台。该入口与播放器使用的 [HTTP 会话接口](server.zh-CN.md) 各自独立。

| 命令 | 输入与行为 |
| --- | --- |
| `status` | 输出 `settings`、`models`、`active_models`、`credentials`、`integrations`、`chatgpt_accounts` 和服务状态。凭据状态只包含模式、文件路径和是否已保存直填密钥。 |
| `cloud-usage` | 读取默认缓存目录中的 UTC 周汇总，无需启动字幕服务。 |
| `preset-check [requirements]` | 检查 FFmpeg 和逗号分隔的 `vulkan`、`cuda`、`dashscope` 条件，返回缺项代码 `missing`。stdin 可提供 `{"qwen_mt_url": "…"}` 检查候选地址，密钥使用已保存配置。 |
| `install <model>` / `uninstall <model>` | 下载或卸载指定本地模型。标识见控制模块中的 `MODELS`。 |
| `apply` | 从 stdin 读 JSON 设置，支持同时提交可选的 `credentials` 更新。验证后重启后台。 |
| `save-credentials` | 从 stdin 接收 `{供应商标识: {mode, value}}`。`openai`、`dashscope`、`minimax`、`compatible-asr` 和 `compatible-mt` 支持 `direct`、`file` 和 `default`。保存后返回凭据状态，正在运行的服务继续用启动时加载的密钥。 |
| `chatgpt-status` | 列出已保存的 ChatGPT 账号、授权状态及缓存的模型。 |
| `chatgpt-login [account]` | 在系统浏览器打开 ChatGPT 授权。带账号标识时重新授权对应注册。 |
| `chatgpt-models <account>` | 刷新账号的可用模型。 |
| `chatgpt-logout <account>` | 尝试撤销远端会话并清除本机令牌，保留账号注册。 |
| `stop` | 停止助手管理的服务。 |
| `integrate potplayer\|mpv [--folder PATH]` | 配置播放器接入。可指定并记住自定义位置。 |
| `unintegrate potplayer\|mpv` | 移除所选位置的 AheadSubs 扩展文件。 |
| `pot-windows` | 列出当前可操作的 PotPlayer 窗口。 |
| `pot-start <window>` / `pot-stop <window>` | 开启或停止对应窗口的预读。 |
| `logs` | 输出可以查看的日志路径。 |
| `inspect-library` | 读取本地缓存，返回按路径归并的 `files`，含版本、覆盖率和语言摘要。 |
| `inspect-rows <key>` | 返回指定版本最近的原文、字幕和失败行。 |
| `inspect-regenerate <key>` | 向运行中的桌面服务排队，返回新版本的 `key`。 |
| `inspect-srt <key>` | 从 stdin 读取 `{"output":"…"}` 并返回 `subtitle` 路径。目标为 `null` 时写入缓存内用于查看的 SRT。 |
| `automation [mcp-enable\|mcp-disable\|cli-install\|cli-remove]` | 返回 MCP 开关、客户端配置和 CLI 的用户 PATH 注册状态。指定操作时直接更新对应状态。详见[接入说明](automation.zh-CN.md)。 |
| `folder-tasks [save\|retry]` | 返回规则与队列摘要。`save` 从 stdin 读取 `{rules: [...]}` 并替换已保存的规则。可选的 `speech_model` 和 `translation_model` 分别接受 `whisper-small`、`qwen-mt-flash` 等模型标识。省略某个字段或传 `null` 时沿用全局设置。`retry` 读取 `{id: "规则 ID"}` 并重新排队该规则的失败文件。 |

每次调用向 stdout 输出一个 JSON 对象，带 `ok` 布尔值。失败时带 `error` 并返回非零退出码。它是项目内的桌面控制接口，外部适配器应以公开的 HTTP v1 合约为准。

[Windows 用户数据目录](windows.zh-CN.md)保存 `settings.json`、模型、缓存和控制令牌。独立启动并使用不同控制令牌的服务由其启动方管理。源码入口是 `AheadSubs.pyw`。`Subtitle Relay.pyw` 继续接收已安装的播放器扩展发来的回调。

ChatGPT 账号凭据保存在用户数据目录的 `chatgpt.sqlite3` 中，由当前 Windows 用户的 DPAPI 加密。桌面桥接只返回账号概要、授权状态和模型目录。设置保存选中的账号及模型标识。
