# 文档配图

[English](README.md) | [简体中文](README.zh-CN.md)

README 流程图展示：播放器进度 → 有界音频预读 → 本地/云端识别与翻译 → 带时间轴的 SRT/缓存字幕 → 加载到播放器。下方区分已播放区域、播放头、前方准备的字幕片段。这是概念图，不是程序截图，也不保证每条字幕都已就绪。

- 英文：[概览图](aheadsubs-overview.png)。
- 简体中文：[概览图](aheadsubs-overview.zh-CN.png)，以英文图为参考，保持相同布局进行文字翻译。
- 使用内置 `image_gen` 工具生成，[提示词规格和翻译映射](prompts.json)保存最终设计要求；没有调用需 API Key 的 CLI。
- [manifest.json](manifest.json)登记语言配对。新增含文字图必须双语，无文字共用图需显式登记，不能静默豁免。

检查两张图的文字、箭头和可读性。自动检查仅验证配对文件和对应语言引用，含义及翻译仍需人工/Agent 检查。使用图的每种语言页面都应有对应图注与替代文本。
